# PIK Exchange Bot

رباتِ تلگرامیِ صرافیِ کوچک برای خرید/فروش **روبل** و **دلار**، با نرخ لحظه‌ای از
[alanchand.com](https://alanchand.com/en)، پنل مدیریت داخل تلگرام، و نصب/آپدیت یک‌خطی
روی سرور (مثل ربات اطلس).

## امکانات

- خرید روبل با **۵ گزینهٔ حجمی** (۳ تینکوف و ۲ تک‌فیش)، با ضریب و آفست مستقل.
- حسابداری دستی ورودی/خروجی با «نام - مبلغ به تومان»، فهرست مرتب، جمع و مانده.
- خرید **روبل تک‌فیشی**، **دلار نقدی**، **فروش دلار مهردار/کهنه**، **خرید تومان با روبل**.
- نرخ‌ها یا **فرمولی** (نرخ سایت × ضریب) هستند یا **دستی** (مقدار ثابت ادمین).
- نمایش **قوانین معاملات**، دکمه‌ی موافقت و **دریافت کارت**، سپس **ارسال فیش** و تأیید توسط ادمین.
- **معاملات من** برای کاربر.
- **پنل مدیریت داخل تلگرام**: تنظیم ضریب‌ها و پله‌ها، شماره کارت، نرخ دلار، متن قوانین/خوش‌آمد/پشتیبانی،
  مشاهده و تأیید تراکنش‌ها، حسابداری ورودی/خروجی، پیام همگانی، نرخ لحظه‌ای سایت.
- نصب نسخهٔ جدید و ری‌استارت ربات، پیام آپدیت برای کاربران یا ادمین‌ها ارسال نمی‌کند.
- دستور مدیریتی ترمینال: `pik` (شبیه `x-ui`).

## پیش‌نیاز: تنظیم آدرس ریپازیتوری

قبل از نصب یک‌خطی، فایل [`bootstrap.sh`](bootstrap.sh) را ویرایش کنید و مقدار `REPO_URL`
را با آدرس ریپازیتوری گیت‌هاب خودتان جایگزین کنید (یا هنگام اجرا `REPO_URL=...` بدهید):

```bash
REPO_URL="https://github.com/majazi041999-spec/PIKExchange.git"
```

## نصب یک‌خطی

```bash
bash <(curl -Ls https://raw.githubusercontent.com/majazi041999-spec/PIKExchange/main/bootstrap.sh)
```

این کار:
1. ریپو را در `/opt/PIKExchangeBot` کلون/به‌روزرسانی می‌کند.
2. `install.sh` را اجرا و توکن/ادمین/پشتیبانی را می‌پرسد.
3. سرویس `pik-bot` را می‌سازد و اجرا می‌کند.
4. دستور `/usr/local/bin/pik` را نصب می‌کند.

هنگام نصب این‌ها را وارد می‌کنید:

| مقدار | توضیح |
|-------|-------|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها از [@userinfobot](https://t.me/userinfobot) (با کاما جدا کنید) |
| `SUPPORT_USERNAME` | آیدی/لینک پشتیبانی که به کاربر نشان داده می‌شود |

## آپدیت

```bash
pik update
# یا
bash <(curl -Ls https://raw.githubusercontent.com/majazi041999-spec/PIKExchange/main/bootstrap.sh) update
```

آپدیت به‌صورت امن انجام می‌شود (auto-stash تغییرات محلی، نصب پکیج‌های جدید، ری‌استارت سرویس).

## فقط تنظیم مجدد توکن/ادمین

```bash
pik configure
```

## دستور `pik` (مدیریت ترمینال)

بعد از نصب کافیست بزنید:

```bash
pik
```

منوی تعاملی باز می‌شود. حالت دستوری هم دارد:

```bash
pik status      # وضعیت سرویس
pik logs        # لاگ زنده
pik restart     # ری‌استارت
pik update      # آپدیت امن
pik configure   # تنظیم .env
pik uninstall   # حذف سرویس (داده‌ها می‌مانند)
```

## پنل مدیریت (داخل تلگرام)

ادمین دستور `/admin` را می‌زند یا از منوی اصلی دکمه‌ی «🛠 پنل مدیریت» را انتخاب می‌کند.

- **💱 نرخ‌ها و محصولات** — برای هر محصول: ضریب پله‌ها، سقف‌ها، برچسب، ستون سایت (خرید/فروش/میانگین)،
  حالت دستی/فرمولی و نرخ دستی. پیش‌نمایش نرخ لحظه‌ای هم نمایش داده می‌شود.
- **💳 مدیریت کارت‌ها** — چند کارت واریز ثبت کنید (هر کدام یک برچسب + متن کامل)، و انتخاب کنید ربات
  کدام را نشان دهد. هنگام دریافت کارت، ربات **دو پیام** می‌فرستد: تأیید+نرخ، سپس متن کارت به‌صورت جدا.
- **📝 متن‌ها** — قوانین معاملات، خوش‌آمد، پشتیبانی.
- **📊 تراکنش‌ها** — لیست و تأیید/رد فیش‌ها. هنگام تأیید، مبلغ واریزی را می‌پرسد و **معادل** آن را
  حساب و به کاربر اعلام می‌کند (مثلاً «۱۲۰٬۰۰۰٬۰۰۰ تومان به نرخ ۲۱۸۰ معادل ۵۵٬۰۴۶ روبل»). پس از تأیید،
  ابزار ارتباط با کاربر (لینک مستقیم یا پیام از طریق ربات).
- **📈 نرخ لحظه‌ای سایت** — مقایسهٔ روبل و دلار در Bonbast، الان‌چند و TGJU؛ تتر در الان‌چند، نوبیتکس و والکس. همهٔ اعداد به تومان و همراه زمان دریافت هستند. TGJU برای روبل/دلار و الان‌چند برای تتر قیمت شاخص ارائه می‌کنند؛ نوبیتکس و والکس بهترین سفارش خرید/فروش بازار را نشان می‌دهند.
- **👥 مشترکین و درخواست نرخ** — تعداد کل، فعال و بن‌شده، صفحه‌بندی ۸تایی، مشخصات و پنج درخواست آخر هر کاربر، بن و آنبن. دستور مستقیم: `/subscribers`.
- **🗂 بایگانی کارت‌های کاربران** — ذخیره با نام صاحب حساب و بانک، جست‌وجوی نام فارسی/روسی/لاتین، چند حساب برای هر نفر، صفحه‌بندی، کپی کارت/شبا/حساب/تلفن، ویرایش و حذف. دستور مستقیم: `/cards`. از پروفایل هر مشترک نیز کارت‌های او در دسترس‌اند. اطلاعات معتبرِ چهارخطیِ تسویهٔ روبل، شامل سوابق موجود، خودکار بایگانی می‌شوند.
- نشان بانک‌ها در بایگانی و فاکتورها با [پک ایموجی متحرک PIK Banks · @Bahram_ru](https://t.me/addemoji/PIK_Banks_Bahram_ru_by_PIKexchange_bot) نمایش داده می‌شود.
- **📢 پیام همگانی** — ارسال پیام به همه‌ی کاربران.
- **🎨 دکمه‌های رنگی** — روشن/خاموش کردن رنگ دکمه‌ها (پیش‌فرض: خاموش).
- **⏸ حالت معلق** — با روشن‌کردنش، واریز مستقیم غیرفعال می‌شود و کاربر ابتدا به هماهنگی با پشتیبانی
  هدایت می‌شود (نرخ همچنان نمایش داده می‌شود).

**مرجع معاملات:** فقط `bonbast.com` است. نرخ سایر منابع برای مقایسه نمایش داده می‌شود.
در قطعی Bonbast، آخرین نرخ آن حداکثر ۵ دقیقه معتبر است؛ بعد از آن نرخ معامله در دسترس نیست.
در پنل مقایسه، نرخ ذخیره‌شده یا دریافت‌نشده با علامت هشدار مشخص می‌شود. درخواست‌های مقایسه
همزمان و با کش ۶۰ثانیه‌ای اجرا می‌شوند؛ تازه‌سازی متوالی تا ۱۰ ثانیه دوباره سایت‌ها را فراخوانی نمی‌کند.

هر نرخ که به کاربر عادی نمایش داده شود در دیتابیس ثبت و برای **همه ادمین‌ها** ارسال می‌شود،
همراه نام، آیدی، محصول، نرخ و تعداد درخواست‌های او. دریافت تکراری یک رویداد تلگرام دوباره
اعلان نمی‌فرستد. درخواست خود ادمین‌ها اعلان ندارد. سابقهٔ نرخ‌ها از زمان نصب این نسخه ثبت می‌شود.
بن از تمام منوها، مشاهدهٔ نرخ، ثبت معامله و ارسال فیش جلوگیری می‌کند و با ری‌استارت باقی می‌ماند.
ادمین‌ها قابل بن‌کردن نیستند. آنبن، دسترسی همان کاربر را بازمی‌گرداند.

## فرمول نرخ‌ها (پیش‌فرض)

نرخ روبل از **ستون فروش** سایت به **تومان** تبدیل می‌شود (مقدار ریالی ÷ ۱۰) و سپس:

| محصول / پله | ضریب |
|-------------|------|
| تینکفی — زیر ۵۰ میلیون تومان | ۰٫۹۳ |
| تینکفی — ۵۰ تا ۲۰۰ میلیون تومان | ۰٫۹۲ |
| تینکفی — بالای ۲۰۰ میلیون تومان | ۰٫۹۱۵ |
| تک‌فیش — زیر ۳۰ میلیون تومان | ۰٫۹۶۵ |
| تک‌فیش — بالای ۳۰ میلیون تومان | ۰٫۹۶ |

نرخ محصولات ساده = **مبنا × ضریب + آفست**:

| محصول | مبنا | فرمول | واحد نتیجه |
|-------|------|-------|-----------|
| خرید تومان با روبل — زیر ۲۰ هزار روبل | نرخ فروش روبل سایت | مبنا − ۳۰۰ | تومان |
| خرید تومان با روبل — بالای ۲۰ هزار روبل | نرخ فروش روبل سایت | مبنا − ۴۰۰ | تومان |
| فروش دلار مهردار/کهنه | دلار→روبل بانک روسیه (CBR) | مبنا − ۸ | **روبل** |
| خرید دلار نقدی | دلار سایت | مبنا × ۱ | تومان |

> ضریب‌ها و آفست‌ها از پنل تلگرام قابل تغییرند؛ آفست پیش‌فرض خرید روبل صفر است. بازه‌های خرید روبل ثابت‌اند. برای دلار مهردار می‌توانید نرخ
> دقیق اسبر را دستی وارد کنید (اولویت با نرخ دستی است)؛ در غیر این صورت از نرخ رسمی بانک روسیه
> استفاده می‌شود. (سایت خود اسبربانک از خارج روسیه API قابل‌دسترسی ندارد.)

## ساختار پروژه

```
main.py                 # نقطه‌ی ورود؛ راه‌اندازی ربات + ورکر تازه‌سازی نرخ
core/
  config.py             # خواندن .env
  db.py                 # SQLite (کاربران، تراکنش‌ها، تنظیمات، حسابداری)
  products.py           # تعریف محصولات و بازنویسی‌های ذخیره‌شده
  rates.py              # دریافت نرخ از سایت + محاسبه‌ی نرخ محصولات
  market.py             # مقایسهٔ مستقل منابع و نرخ تتر
  subscribers.py        # مشترکین، بن/آنبن و سابقهٔ درخواست نرخ
  activity.py           # اعلان درخواست نرخ برای همه ادمین‌ها
  texts.py              # متن‌های پیش‌فرض (قوانین/خوش‌آمد/پشتیبانی)
  jalali.py, utils.py   # تاریخ شمسی و ارقام فارسی
bot/
  keyboards.py          # کیبوردهای اینلاین
  states.py             # حالت‌های FSM
  handlers/
    user.py             # منو، نرخ، قوانین، دریافت کارت، ارسال فیش
    admin.py            # پنل مدیریت
install.sh update.sh setup_service.sh bootstrap.sh uninstall.sh pik_menu.sh
```

## اجرای دستی (بدون سرویس، برای تست محلی)

```bash
python3 -m venv .venv
source .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env           # سپس BOT_TOKEN و ADMIN_IDS را پر کنید
python main.py
```

## حسابداری دستی

در چت خصوصی ادمین، `/accounting` یا «📒 حسابداری ورودی / خروجی» را انتخاب کنید.
«ثبت ورودی» یا «ثبت خروجی» را بزنید و نام و مبلغ را در یک خط بفرستید:

```text
میرحسین - ۱۰۰٬۰۰۰٬۰۰۰
```

همهٔ مبالغ به **تومان** هستند؛ نوشتن «تومان» در انتهای عدد اختیاری است.
ارقام فارسی/عربی/لاتین و جداکننده‌های هزارگان پذیرفته می‌شوند.
قبل از ثبت، نام، مبلغ، جهت و شرح قابل اصلاح است. با تأیید، فهرست مرتب اسناد
به همراه جمع ورودی، جمع خروجی و مانده نمایش داده می‌شود. هر سند نام، مبلغ،
نوع، وضعیت و تاریخ شمسی دارد. گزارش صفحه‌بندی شده و اسناد از دکمهٔ شمارهٔ سند باز می‌شوند.
اسناد در انتظار وصول تا زمان تأیید در مانده اثر ندارند. ابطال با تأیید جداگانه انجام می‌شود
و سابقهٔ سند باقی می‌ماند. دوبار زدن دکمهٔ تأیید، ثبت تکراری ایجاد نمی‌کند.

این دفتر مستقل از معاملات کاربران است. پردازش تصویر حذف شده و نیازی به کلید API ندارد.
ارسال معمول فیش معامله برای بررسی ادمین همچنان برقرار است. کیف پول و شارژ آن از منوها
و عملیات ربات حذف شده‌اند؛ ستون‌های موجود در دیتابیس قدیمی برای حفظ سابقه دست‌نخورده می‌مانند.

## روش محاسبهٔ نرخ خرید روبل

برای هر یک از ۵ گزینهٔ خرید روبل، **فقط یک روش** فعال است:

- ضریب: نرخ سایت × ضریب؛ آفست ذخیره‌شده اعمال نمی‌شود.
- آفست: نرخ سایت + آفست؛ ضریب ذخیره‌شده اعمال نمی‌شود.

مثلاً نرخ سایت ۳٬۳۵۰ و آفست ‎−۲۷۰ نتیجهٔ ۳٬۰۸۰ تومان می‌دهد.
ذخیرهٔ ضریب یا آفست همان روش را فعال می‌کند؛ دکمهٔ تغییر روش نیز در هر پله وجود دارد.
در ارتقا، پله‌ای که آفست غیرصفر دارد در حالت آفست قرار می‌گیرد و بقیه در حالت ضریب.

تست‌ها با دیتابیس موقت و بدون اتصال به تلگرام اجرا می‌شوند:

```bash
python -m unittest discover -s tests -v
```
